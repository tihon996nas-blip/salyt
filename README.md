# 🔊 Салют — утренний пост с джазовым плеером

Telegram-бот **@morning_salyt_bot** публикует в канале пост с картинкой колонки и кнопкой «🎵 Включи».
По нажатию открывается мини-плеер прямо поверх Telegram (Telegram WebApp) — пользователь никуда не переходит.

---

## Структура проекта

```
salyut/
├── index.html      # плеер (деплоится на GitHub Pages)
├── jazz.mp3        # трек (добавь сам, не включён в репозиторий)
├── kolona.jpg      # картинка колонки для поста (добавь сам)
├── send_post.py    # скрипт отправки поста через бота
└── README.md
```

---

## Быстрый старт

### 1. Задеплой плеер на GitHub Pages

1. Создай публичный репозиторий, например `salyut`
2. Положи в него `index.html` и `jazz.mp3`
3. Зайди в **Settings → Pages → Branch: main → / (root) → Save**
4. Через минуту плеер будет доступен по адресу:
   ```
   https://<твой_username>.github.io/salyut/
   ```

### 2. Настрой бота у @BotFather

Выполни в чате с @BotFather:

```
/setdomain
```
Выбери @morning_salyt_bot и введи домен:
```
<твой_username>.github.io
```
Это обязательно — без этого кнопка `web_app` не откроется.

### 3. Добавь бота в канал/группу

- Открой канал → **Администраторы → Добавить администратора**
- Найди @morning_salyt_bot
- Включи права: **Публикация сообщений**

### 4. Установи зависимости

```bash
pip install python-telegram-bot
```

### 5. Отредактируй send_post.py

Открой `send_post.py` и замени две строки:

```python
CHAT_ID    = "@название_твоего_канала"
WEBAPP_URL = "https://твой_username.github.io/salyut/"
```

### 6. Запусти

```bash
cd путь/к/папке/salyut
python send_post.py
```

## Как это выглядит для пользователя

1. Видит пост в группе: картинка колонки + текст + кнопка **🎵 Включи**
2. Нажимает кнопку — поверх Telegram открывается плеер
3. Нажимает ▶ — играет джаз
4. Нажимает ⏹ — музыка останавливается
5. Закрывает плеер — возвращается в группу

Бот ничего не пишет пользователю в личку. Пользователь не проваливается в диалог с ботом.

---

## Частые ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Кнопка не открывается | Домен не привязан к боту | `/setdomain` у @BotFather |
| `❌ Ошибка Telegram` | Бот не админ канала | Добавь бота как администратора |
| `❌ Файл не найден` | Нет kolona.jpg рядом со скриптом | Положи картинку в папку salyut/ |
| Плеер открывается но нет звука | jazz.mp3 не загружен на GitHub | Загрузи файл в репозиторий |
